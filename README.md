# Cryptography

## Overview

A small collection of Java implementations for common cryptographic algorithms.

## Programs

The source files are stored in the `programs/` directory:

1. XOR with 0
2. XOR or AND with 127
3. Simple Ciphers
   1. Caesar Cipher
   2. Substitution: Atbash Cipher
   3. Hill Cipher
4. [Blowfish](programs/Blowfish.java)
5. [DES](programs/DES.java)
6. [RC4 Encryption](programs/RC4Encryption.java)
7. [RSA Algorithm](programs/RSAAlgorithm.java)
8. [Diffie-Hellman Algorithm](programs/DiffieHellman.java)

# Cryptography

## Overview

A small collection of implementations for cryptographic algorithms.

## Programs

The source files are stored in the `programs/` directory:

1. [XOR with 0](programs/xor0.c)
2. [XOR or AND with 127](programs/xorAnd127.c)
3. Simple Ciphers
   1. [Caesar Cipher](programs/CaesarCipher.java)
   2. [Substitution: Atbash Cipher](programs/AtbashCipher.java)
   3. [Hill Cipher](programs/HillCipher.java)
4. [Blowfish Algorithm](programs/Blowfish.java)
5. [DES Algorithm](programs/DES.java)
6. [RC4 Encryption Algorithm](programs/RC4Encryption.java)
7. [RSA Algorithm](programs/RSAAlgorithm.java)
8. [Diffie-Hellman Algorithm](programs/DiffieHellman.java)
